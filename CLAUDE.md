# DiagramIt — working notes for Claude

Browser app (Vite + React 19 + TypeScript + Fabric.js 7) for publication-quality
lab/experimental-design figures. No backend. See README.md for the user-facing
feature list and docs/superpowers/ for the specs and plans that shaped it.

## Commands

```bash
npm run dev          # Vite on :5173 (pass --port N --strictPort if taken)
npm test             # vitest (unit tests; jsdom)
npm run build        # tsc -b && vite build  — must pass before committing
npx tsx scripts/icon-sheet.ts <category> <outDir>   # contact sheet of icons (macOS qlmanage)
```

## Deployment

Public repo `CahanLab/diagramIt`; every push to `master` runs
`.github/workflows/pages.yml` (test, build with `BASE_PATH=/diagramIt/`,
deploy) and publishes https://cahanlab.github.io/diagramIt/ in about a minute.
`vite.config.ts` reads `BASE_PATH` for the asset base; local builds use `/`.
Check a deploy with `gh run list` and a browser visit to the live URL.
Releases: after cutting a version in CHANGELOG.md and package.json and
committing, run `scripts/release.sh` (tags `vX.Y.Z`, publishes a GitHub
release with that CHANGELOG section as notes).

## Architecture map

- `src/canvas/` — Fabric canvas wrapper (`FabricCanvas.tsx`), zustand store
  (`editorStore.ts`, incl. the sketch tool settings), tools (`tools.ts`:
  shapes, segmented line, eraser drag), history (undo/redo snapshots),
  commands (duplicate/group/align/order), snapping guides (`guides.ts`),
  `fit.ts`. Camera lucida sketch tools: pure geometry in `sketch.ts` (path
  data from sketch data, dot scattering, erasing of runs, dots and Fabric
  path commands), Fabric brushes in `brushes.ts` (`InkBrush`,
  `StippleBrush`, `setPathInPlace` which re-renders a path without moving
  it), the vector eraser in `eraser.ts`; sketch objects are `Path`s with
  `data.kind = 'sketch'` and `data.sketch`. Spec:
  `docs/superpowers/specs/2026-10-15-lucida-sketch-tools-design.md`.
- `src/draw/` — shared primitive drawing commands (`Cmd`), Fabric renderer
  (`render.ts`) and SVG previewer (`svg.ts`). Both smart objects emit `Cmd[]`.
- `src/protocol/` — differentiation timeline: `types.ts`, pure `layout.ts`,
  `templates.ts`, `render.ts`, `ProtocolEditor.tsx`.
- `src/ontogeny/` — developmental lineage graphs: `types.ts`, `validate.ts`,
  pure `layout.ts`, `render.ts`, `OntogenyEditor.tsx`, curated data in
  `graphs/*.ts` (registered in `graphs/index.ts`).
- `src/library/` — icon contract (`types.ts`), registry/search, colour tokens,
  Fabric insertion with recolouring (`insert.ts`), parametric generators,
  icon data in `items/<category>.ts`. Developmental stages: embryos are
  traced from the eMouseAtlas Theiler plates (`items/embryos/traced.ts`,
  generated by `scripts/embryos/run.sh`) plus hand-placed features
  (`items/embryos/features.ts`), assembled in `items/embryos/items.ts`;
  limbs are assembled by `items/limbs/build.ts` from authored silhouettes and
  model-derived bone and muscle shapes in `items/limbs/shapes.ts` (generated
  by `scripts/limbs/author.py`, see `scripts/limbs/README.md`) with per-stage
  tissue recipes in `items/limbs/{forelimb,hindlimb}.ts`. Drawing styles
  (basic / camera lucida / realistic) are renderers over these models:
  `generators/limb.ts`, `generators/limbLucida.ts`, `generators/limbRealistic.ts`,
  `items/embryos/model.ts`, with `generators/tone.ts` (path flattener, polygon
  distance, tonal stipple, polygon hatching) behind the camera lucida shading;
  items carry `styles`, the store carries `drawingStyle`, inserted groups carry
  `data.style`, `insert.restyleIcon` re-renders in place. Specs:
  `docs/superpowers/specs/2026-10-14-mouse-embryo-limb-icons-design.md`,
  `docs/superpowers/specs/2026-10-14-drawing-styles-design.md` (phase 5,
  "Reference-built limbs and traced embryos", records the references and
  decisions). Regenerating shapes needs a Python with numpy, scipy,
  scikit-image and Pillow (the maintainer's conda env `nlmprelim`).
- `src/export/` — SVG, PNG, PDF (jsPDF + svg2pdf), PPTX (pptxgenjs), project JSON.
- `src/libraries/` — user-made libraries (`*.diagramit-lib.json`): `types.ts`,
  pure `normalize.ts`/`svg.ts`/`io.ts`, zustand `store.ts` (localStorage,
  registers custom icons with the registry), Fabric-only `capture.ts`.
  Spec: `docs/superpowers/specs/2026-10-07-custom-libraries-design.md`.
- `src/ui/` — panels, toolbar, dialogs. `src/app/App.tsx` wires everything.
- `src/templates/` — starter documents loaded by File ▸ New.

Smart objects (timeline, ontogeny) are Fabric Groups whose `data` carries the
full model (`data.protocol`, `data.ontogeny = { graph, view }`); double-click
re-opens the editor and `replace*Group` re-renders in place.

## Conventions

- Keep layout engines pure (no DOM, no Fabric) and unit-tested; put Fabric-only
  code in `render.ts`/`insert.ts`. Tests live beside code as `*.test.ts`.
- Every canvas object has `data: ObjectData` (`src/canvas/types.ts`), and it is
  included in all serialisation via `SERIALIZE_PROPS` in `canvas/commands.ts`.
- Fabric 7: default origin is `center`; always set `originX/originY: 'left'/'top'`
  on objects we position. Raster export must run with guides detached
  (`withoutGuides`). `fabric/extensions` needs the `westures` package.
- Icons: inline SVG strings, viewBox only, allowed elements listed in
  `src/library/types.ts` (gradients in `<defs>` referenced by `url(#id)` are
  allowed; ids must be unique per icon), recolourable regions use
  `#PRIMARY`/`#SECONDARY` and the tint tokens `#PRIMARYL`/`#PRIMARYD`/
  `#SECONDARYL`/`#SECONDARYD` (`src/library/color.ts`).
  The registry test validates every icon; use the icon-sheet script to eyeball.
- Ontogeny graphs: rules in `src/ontogeny/graphs/README.md`; the graphs test
  validates structure. Curated content was authored by subagents from
  references listed in each file's `source`; treat biology edits carefully.
- Dev-only `window.__diagramit` exposes canvas/store/export for Playwright
  checks (used by the maintainer with the Playwright MCP). Fabric listens for
  mouse events (not pointer events) and a double-click needs `detail: 2`, so
  synthetic drawing in tests dispatches `MouseEvent`s on `canvas.upperCanvasEl`
  (moves and ups on `document`). Autosave lives in
  `localStorage['diagramit.autosave.v1']`; clear it to get the fresh sample.
- Writing style in UI copy: British spelling (colour, centre), sentence case.

## Process expectations

- Before implementing a feature: brainstorm → spec in `docs/superpowers/specs/`
  → plan in `docs/superpowers/plans/` (superpowers skills). The owner prefers
  autonomous execution with decisions recorded in the spec.
- Before claiming done: `npm test`, `npm run build`, and a real-browser check of
  the touched UI (Playwright MCP) with a screenshot read back.
- Update `CHANGELOG.md` and bump `package.json` version with every user-visible
  change (policy at the top of CHANGELOG.md). Commit with a conventional
  message (`feat:`, `fix:`, `chore:`, `docs:`).
- Large, independent authoring (icon sets, curated graphs) is a good fit for
  parallel subagents; give them the contract file and the validation command.

## Known gaps / ideas (see CHANGELOG "Unreleased")

- Drosophila (and zebrafish, Arabidopsis) ontogenies not yet curated.
- Label collisions in dense ontogeny trees; a proper label-overlap pass would help.
- PowerPoint "Convert to Shape" on the exported SVG not verified in PowerPoint itself.
- PDF export not visually verified (no rasteriser installed on this machine).
- Only the limb outline icons are in the library (0.11.0); the skeleton,
  muscle and innervation renderers and their tests remain for a later return.
- Limb icons show dorsal views only; no scapula/pelvis, no vessel version.
  Muscle groups are the E14.5 model's masses reused from E13.5 to E18.5;
  digit bones are generated rather than traced.
- Embryos are flat traced silhouettes: the realistic style shows no organs.
- Sketch tools (0.12.0): polylines have no vertex handles after drawing; the
  eraser leaves fills and text alone; erasing a curved icon line flattens the
  touched subpath into straight segments (eight per curve).
- Custom-library SVG sanitiser rejects gradients, so a realistic icon cannot be
  saved as a custom library item.
- PyMuPDF cannot rasterise gradient fills; use `qlmanage -s <max dim>` (or the
  browser) to check realistic icons. Contact sheets of the limb and embryo
  icons: `scripts/limbs/author.py --preview out.svg` (silhouettes only) and
  `npx tsx scripts/icon-sheet.ts development <outDir>`.
