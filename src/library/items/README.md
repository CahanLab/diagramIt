## Developmental stage icons (`development.ts`)

Embryos are hand-authored in `embryos/*.ts`. Limb icons are generated by
`src/library/generators/limb.ts` from per-stage anatomy in `limbs/forelimb.ts`
and `limbs/hindlimb.ts` (spec: `docs/superpowers/specs/2026-10-14-mouse-embryo-limb-icons-design.md`).
Recolourable: `#PRIMARY` limb/embryo tissue (default `#e8c9a0`), `#SECONDARY`
cartilage (default `#5b8fd6`). Fixed tissue colours in the generator:

| Tissue | Colour |
|---|---|
| Precartilaginous condensation | `#SECONDARY` at 0.4 opacity, no outline |
| Periosteal sleeve | `#f3e9d2` band |
| Ossifying diaphysis (Alizarin) | `#c0392b` band |
| Muscle | `#b84a3f` at 0.85 opacity |
| Tendon | `#f5efe0` band |
| Nerve | `#d9a400` |
| Apical ectodermal ridge | `#c9a57c` |
